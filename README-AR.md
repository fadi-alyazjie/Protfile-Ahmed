# موقع أحمد اليازجي — دليل التشغيل والتعديل

واجهة بورتفوليو مستوحاة من الصور المرفقة، مبنية باستخدام HTML وCSS وJavaScript فقط. تتضمن الصفحة الرئيسية، نبذة تعريفية، الخدمات، خمسة مشاريع مع نافذة تفاصيل، آراء تجريبية، نموذج تواصل، وتذييل الصفحة.

## تشغيل الموقع

1. فك ضغط `Ahmed-Portfolio.zip` بالكامل.
2. افتح مجلد `Ahmed-Portfolio`.
3. افتح `index.html` في متصفح حديث.

لا تحتاج إلى تثبيت برامج أو حزم، ولا تحتاج إلى الإنترنت لعرض الموقع. أبقِ مجلد `assets` بجوار `index.html`. روابط البريد والهاتف والمواقع الخارجية تستخدم التطبيقات أو الاتصال المتاح على جهاز الزائر.

## الملفات

│   │   ├── data.js            بيانات التواصل والخدمات والمشاريع والآراء

## تغيير النصوص والمعلومات

افتح `assets/js/data.js` في أي محرر نصوص بترميز UTF-8:

- `email` و`phone` و`location`: معلومات التواصل في الواجهة ونموذج البريد.
- `services`: أسماء الخدمات ووصفها.
- `projects`: المشاريع والصور والأوصاف والتسليمات والروابط الخارجية.
- `reviews`: نصوص آراء العملاء وأسماؤهم.
- `socials`: روابط الحسابات الاجتماعية الحقيقية. تظل الروابط غير المعبأة مخفية، حتى لا يظهر زر لا يعمل أو رابط إلى حساب غير صحيح.

النص التعريفي والاسم الكبير وعنوان الصفحة والوصف موجودة في `index.html` ويمكن تعديلها مباشرة. الواجهة باللغة الإنجليزية كما في المراجع؛ الدليل باللغة العربية.

### إضافة مشروع

أضف عنصرًا إلى مصفوفة `projects` بنفس البنية:

```js
{
  id: 'my-project',
  name: 'My project title',
  client: 'CLIENT NAME',
  category: 'Brand identity / Packaging',
  image: 'assets/images/my-project.jpg',
  position: null,
  description: 'Write the real project description here.',
  deliverables: 'Logo, packaging, brand guidelines',
  url: ''
}
```

ضع الصورة الجديدة داخل `assets/images`. استخدم `id` فريدًا بحروف إنجليزية، دون مسافات. يظهر المشروع تلقائيًا في قائمة المشاريع، وتعمل معه نافذة التفاصيل وأزرار التالي والسابق. ترتيب شبكة المعاينات أعلى الموقع قابل للتغيير من `mosaicOrder` في `app.js`؛ تبدأ أرقام العناصر من الصفر.

عند توفير رابط صحيح في `url` يظهر زر لزيارة المشروع الحقيقي. إذا بقي فارغًا، يقود الزر إلى قسم التواصل. صور التفاصيل الجانبية هي اقتصاصات بصرية للصورة التجريبية نفسها؛ يمكن تطوير البيانات لإضافة صور منفصلة لكل مشروع لاحقًا.

## استبدال الصور

يمكنك استبدال ملفات JPG مع الاحتفاظ بالأسماء، أو تغيير مساراتها في `data.js`. الصورة الشخصية مرتبطة مباشرة داخل `index.html`. يفضّل استعمال صور مربعة للمشاريع بحجم 800×800 أو أكبر، وصورة شخصية مربعة بخلفية داكنة. يُجري التنسيق اقتصاصًا تلقائيًا ليتناسب مع البطاقات.

الصور البديلة مولّدة باستخدام أداة image_gen وليست صور الأعمال أو الشخص الأصلي. الصور، أسماء المشاريع، وآراء العملاء أمثلة للتطوير؛ استبدلها بمحتوى حقيقي قبل تقديم الموقع على أنه معرض أعمال فعلي. وصف توليد الصور محفوظ في `ASSET-NOTES.txt`. معلومات التواصل والنص التعريفي مقتبسة من المرجع، وتحتاج إلى مراجعتك عند التخصيص.

## الألوان والحركات

غيّر المتغيرات في بداية `assets/css/style.css`، مثل:

```css
--ink: #101010;
--paper: #eeeeee;
--lime: #c4ff35;
--purple: #aa38f4;
--orange: #ffad42;
```

تتضمن الواجهة ظهور الأقسام أثناء التمرير، حركة العناصر الزخرفية، وتأثيرات على الأزرار والصور. زر `Motion` يوقف الحركات أو يشغّلها، ويحفظ هذا الاختيار على الجهاز عند توفر التخزين المحلي. تُحترم إعدادات تقليل الحركة في نظام الزائر. يوجد تنسيق للجوال والأجهزة اللوحية والشاشات الكبيرة. تعتمد الخطوط على المتاح في الجهاز، لذلك قد يختلف شكل الخط قليلًا بين الأنظمة.

## نموذج التواصل

النموذج يتحقق من الاسم والبريد ونص الرسالة، ثم يجهّز رسالة عبر `mailto:` ويفتح تطبيق البريد إن كان متاحًا. الزائر يراجع الرسالة ويرسلها بنفسه. تظهر أيضًا نسخة قابلة للنسخ إذا لم يكن تطبيق البريد مضبوطًا، أو كانت الرسالة طويلة.

**الموقع لا يرسل البريد مباشرة ولا يملك خادمًا أو قاعدة بيانات.** لا يظهر تأكيد وهمي بوصول الرسالة. لإضافة إرسال مباشر مستقبلًا، اربط حدث الإرسال في `app.js` بخادم أو خدمة نماذج مناسبة. لا تضع مفاتيح سرية داخل ملفات JavaScript العامة. لا تُخزَّن بيانات النموذج محليًا أو تُرسل إلى خدمة تحليلية.

## التفاعلات

- التنقل بين الأقسام من القائمة وأزرار التواصل.
- قائمة قابلة للفتح والإغلاق على الجوال.
- فتح المشاريع من البطاقات أو شبكة المعاينات.
- استعراض المشروع السابق أو التالي داخل نافذة التفاصيل.
- إغلاق النافذة بالزر، أو Escape، أو النقر خارجها، مع إعادة التركيز إلى الزر الأصلي.
- تمرير آراء العملاء باللمس أو السحب أو أزرار الأسهم أو لوحة المفاتيح.
- التحقق من نموذج التواصل وتجهيز الرسالة ونسخها.
- إيقاف الحركات وتفعيلها، والعودة إلى أعلى الصفحة.

## التطوير والنشر لاحقًا

الملفات مستقلة ولا تستخدم CDN أو مكتبات خارجية. يمكن رفع محتويات المجلد إلى استضافة تدعم الملفات الثابتة. لا يحتاج المشروع إلى خطوة بناء. لم تُنشر هذه النسخة على الإنترنت؛ التسليم هو مجلد محلي وحزمة ZIP كما طُلب.

جرى التحقق من صحة JavaScript وروابط الملفات المحلية وبنية الأقسام. تعذّرت معاينة المتصفح داخل بيئة الإنشاء بسبب منع فتح الملفات المحلية. يُنصح بفتح `index.html` على المتصفح والجوال قبل النشر العام، خاصة بعد استبدال النصوص والصور.
